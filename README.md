# Основной геймплей 
Игрок управляет перекрёстком (или несколькими) и: переключает светофоры (кнопки / клики),
следит за потоком машин, предотвращает аварии
# Ключевые механики 
1. Светофоры: 2 состояния зеленый/красный, игрок вручную переключает
2. Машины: Едут по дорогам, останавливаются на красный, если впереди машина - тоже останавливаются
3. Шкала агрессии. У каждой машины есть терпение, если долго стоит - проезжает на красный, когда "терпение" заканчивается
4. Спецтранспорт - фишка проекта. Скорая/полиция едут быстрее (игнорируют правила, игрока должен подстроится)
# Уровни
1 уровень - самый простой, таймер 15 секунд, за это время игрок не должен врезаться
2 уровень - более сложный, таймер уже на 30 секундах, смысл игры остается
Уровень HARD добавленние еще одного участка дороги. Больше светофоров, машин, вероятности попасть в аварию. Нужно продержаться 30 секунд, чтобы пройти игру
# Конец игры
Авария- если две машины пересеклись, сразу Game Over
